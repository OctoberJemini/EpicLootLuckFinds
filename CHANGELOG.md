# Changelog

## 1.5.2

- Added the public source repository and issue-reporting link.
- Clarified descriptions and tables: creature gear 1%, bounty gear 5%, vendor offers 5%, triple-coin bounties 20%.
- No gameplay changes from 1.5.1.

## 1.5.1

- Creature lucky equipment chance: 1%.
- Bounty next-region equipment chance: 5%.
- New vendor lucky equipment offer chance: 5%.
- Split the shared equipment chance into separate settings.
- Triple-coin bounties remain at 20%. Saved vendor offers retain their outcomes until refresh.

## 1.5.0

- Added a fixed 20% chance for newly evaluated bounty offers to pay triple coins.
- Added a gold Lucky Bounty label and tooltip; the increased reward is displayed before acceptance.
- Saved offer outcomes per world/player/bounty so browsing, relogging, and abandoning cannot reroll or multiply rewards again.
- Preserved accepted contracts, tokens, equipment rewards, target difficulty, and the existing 0.5% lucky equipment chance.
- Expanded compatibility checks to 84 requirements; API/build checks pass for Epic Loot 0.15.1–0.15.4.
- Added 100,217 automated bounty reward checks. Live in-game verification remains pending.
## 1.4.1

- Replaced the Epic Loot 0.15.4 exact-version restriction with startup API compatibility checks.
- Verified API and compilation compatibility with Epic Loot 0.15.1 through 0.15.4.
- Newer Epic Loot releases may load if required APIs and patch patterns remain compatible.
- Added an isolated bootstrap so compatibility checks run before the Epic Loot-dependent engine is loaded.
- Keep gameplay changes inactive until all patches install successfully; remove this mod's patches if installation fails.
- Preserve existing settings and vendor stock history.
- Updated compatibility documentation. In-game verification remains pending.

## 1.4.0

- Initial public beta package: progression-capped creature equipment, regional bounty rewards, persistent lucky vendor stock, and a one-time discovery chime.
- Chest, clover, and OCT icon; full progression tables.
